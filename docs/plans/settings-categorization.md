# Settings Categorization

Reorganize the existing settings around the concepts users configure instead of
using “General” and one broad “Recording” group.

- **Dictation** owns activation, audio input, feedback, and debug-only tools.
- **Transcription** owns provider configuration and language configuration.
- **System Access** owns permissions, keyboard setup, and runtime readiness.

The preference model and persistence keys remain unchanged. Future
post-processing can begin as a Transcription section, while per-app formatting
can grow into an Output page without turning General into a catch-all.
